# 泛微知识库问答助手

基于 Qwen2.5 + Chroma 的本地知识库问答系统。

## 效果示例
问：泛微有多少客户？
答：85,000+ 中大型组织客户，覆盖87个细分行业。

## 技术栈
- Qwen2.5-3B-Instruct (INT4)
- BAAI/bge-small-zh-v1.5 (Embedding)
- Chroma (向量数据库)
